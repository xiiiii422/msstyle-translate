一句话总结

本工具是一个纯静态网页。它没有自己的服务器， 不会把你的数据发送给本站的作者或任何第三方广告商。

你的输入内容去哪了

点击「开始翻译」后，你输入的文本会直接由你的浏览器发送到 智谱开放平台 的接口用于生成结果。这条请求不经过本站的任何服务器。 该文本在智谱侧的处理方式，适用智谱开放平台的隐私政策。

API Key

如果你在「设置」里填写了自己的 API Key，它会被 以明文形式保存在你自己浏览器的 localStorage 中 （键名 msstyle_translate_apikey_v1），并且不会过期。 这样你下次打开页面时就不用重新填写。

  • 本站不会把 Key 发送到除你所配置的模型接口（默认为智谱 open.bigmodel.cn）之外的任何地方。
  • 但请注意：localStorage 中的内容没有加密。任何能在本页面运行的脚本、或者与你共用这台电脑的人，都可能读到它。
  • 因此请不要在这里填写权限过大或余额充足的 Key，建议使用额度受限的测试 Key。
  • 你可以随时点「设置 → 清除我的 Key」把它从浏览器中删除。
  • 本站内置了一个用于公共体验的 Key，它以加密形式存放，普通访客看不到明文。 但请理解：任何在前端使用的 Key 都可能被有心的技术用户提取出来， 所以它只适合额度受限的测试用途，绝不是"保密"手段。

本地存储

本站使用浏览器 localStorage 保存以下内容，全部只存在你自己的设备上：

  • 最近 10 条翻译历史（含原文、结果、时间、模式）
  • 你选择的翻译程度
  • 你填写的 API Key（如果有）与模型选择
  • 输入框里没来得及翻译的草稿 —— 这样误刷新或切后台被回收时不用重新打字。 最多只存 2000 字，点「清空」时会一并删除。

清除浏览器数据即可全部抹掉。在页面上：「清空历史」删除翻译历史， 「设置 → 清除我的 Key」删除 Key，清空输入框则删除草稿。
